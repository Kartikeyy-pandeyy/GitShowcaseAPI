Simple API Integration

Get started with our developer-friendly API in just two simple steps. Perfect for integrating portfolio data into your own applications.

1

Register a GitHub User

Tell our system to start tracking a GitHub profile

This creates a new portfolio entry and begins monitoring the GitHub profile for updates. You only need to do this once per user. 

POST https://2at5n0ofhc.execute-api.us-east-1.amazonaws.com/dev/register
Content-Type: application/json

{
  "username": "your-github-username"
}
2

Fetch Portfolio Data

Get the complete portfolio with stats and top repositories

Returns comprehensive portfolio data including user info, GitHub stats, and top repositories ranked by our algorithm. Data is automatically updated every hour. 

POST https://2at5n0ofhc.execute-api.us-east-1.amazonaws.com/dev/showcase
Content-Type: application/json

{
  "username": "your-github-username"
}

Frequently Asked Questions

Everything you need to know about GitShowcaseAPI and how it works.

How often is my portfolio updated?

Your portfolio is refreshed automatically every hour using our backend Lambda functions that pull your latest GitHub profile, repositories, stars, and commits. You can also trigger a manual refresh if you want immediate updates.

What data do you fetch from GitHub?

We only fetch publicly available data from your GitHub profile: username, avatar, bio, repositories, stars, forks, and commit counts. We never access your private repositories.

Is my GitHub account safe?

Yes. We do not ask for your GitHub password. We use a secure GitHub Personal Access Token (PAT) on our backend to fetch data. All data access is read-only and limited to public information.

Can I delete my portfolio?

Absolutely. Reach out to us via the footer contact link, and we will permanently remove your data from our database within 24 hours.

Can I customize the design?

Yes, the frontend is customizable. You can adjust the theme, colors, and layout to match your personal style, or even host it yourself if you'd like full control.

How are top repositories selected?

We use a ranking formula that considers multiple signals to highlight your most impactful work. Each repository is given a score based on:

  • Stars → weighted ×3 (community appreciation)
  • Forks → weighted ×2 (usefulness & adoption)
  • Your commits → weighted ×0.5 (your level of activity)
  • Recent activity → up to +10 points (boost for repos updated within the last year)

The formula looks like this:

score = (stars × 3) + (forks × 2) + (commits × 0.5) + recency_boost

Repositories are sorted by this score, and the top 10 are displayed in your portfolio. Empty repos are given 0 commits but can still rank if they have stars or forks.

Does this count my private commits?

No, only commits to your public repositories are counted. GitHub's API does not expose private repo data unless explicitly authorized, which we do not request.

What happens if my repo is empty?

If a repository has no commits, we display it with 0 commits. It may still appear in your portfolio if it has stars or forks.

What if I change my GitHub username?

If you change your GitHub username, you'll need to re-register with the new username so we can sync your portfolio correctly.

Will this affect my GitHub account in any way?

No. We only read data using GitHub's public APIs. Nothing is written back to your GitHub account, so your profile and repositories remain untouched.
